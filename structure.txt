Features
- Add, view, search, and update products
- Register and manage suppliers
- Manage warehouse storage locations
- Record incoming stock
- Record outgoing stock
- Prevent stock from becoming negative
- Track stock movement history
- Set minimum stock levels
- Generate low-stock alerts
- Generate inventory valuation reports
- View stock by warehouse location
- Store records in JSON files

Tech stack
- Python
- JSON
- Datetime
- UUID
- OS
